# ThEndorSemenT — repo guide

This is a **document and asset repository** for ThEndorSemenT (Thendor), the Web3 digital arm of the Portuguese cooperative **Uma Boa Questão (UBQ)**. There is no code, no build system, no tests, and no CI/CD pipeline.

## Structure

| Path | Contents |
|---|---|
| `XMA/` | Brand assets, logos, store photos, site assets for the XMA brand |
| `XMA/Store/` | Product photos for XMA physical store |
| `docs/` | Project documentation (README, timeline, deliverables, reports) |
| `docs/subprojects/` | Per-sub-project docs (brightgov, corruptedpigs, balcony, escryptorium) |
| `docs/thendorsement.txt` | Company philosophy/values (6 pillars) — likely outdated |
| `voucher/` | Voucher PDFs and contracts |
| `candidaturas/` | IAPMEI funding application documents, contracts, certificates |
| `minutas/` | Meeting minutes for NFT CPigs project (2024–2025) |

## What to do here

- **Read or audit documents** — the repo is flat with no conventions. Read files directly.
- **Add new docs** — place them in the most relevant folder; create a new one if none fits.
- **Do not** look for code, packages, tests, or CI — none exist.
