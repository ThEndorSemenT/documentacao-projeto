# Corrupted Pigs

**Website:** https://corruptedpigs.com
**Responsável:** Tiago Quintans (PM) + Nuno Costa (Dev)

## Descrição

Coleção NFT com componente de jogo blockchain. Originalmente "NFT CPigs", o projeto inclui:

- Coleção de NFTs (imagens geradas por design próprio)
- Modos de jogo (STRONG, MULTIPLAYER)
- Integração com blockchain Solana e/ou ICP
- Game Design Document (GDD) de 2 páginas
