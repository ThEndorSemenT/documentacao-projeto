# TheEndorsement — Documentação do Projeto

## Contexto

O **TheEndorsement** é o braço digital da cooperativa **Uma Boa Questão (UBQ)**, financiado pelo **Voucher Startup PRR** (Aviso n.º 21/C16-i02/2025) no valor de **30.000 EUR**, através do **IAPMEI**.

**Período do projeto:** 15/02/2026 — 30/06/2026 (5 meses)

**Objetivo:** Plataforma digital de registo, validação e rastreabilidade de ativos digitais com base em tecnologia blockchain (ICP — Internet Computer Protocol).
